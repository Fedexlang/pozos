Conectá tu app a un Gist privado de GitHub para que tus pozos se sincronicen entre el celu y la PC.

Solo con permiso "gist". Queda guardado en este dispositivo.
Lo encontrás en la URL del Gist, después de tu usuario.
¿Cómo obtener el token y el Gist ID?
  1. Crear el token: ir a github.com/settings/tokens/new, ponerle un nombre (ej. "pozos"), marcar el scope gist, generar y copiar el token (se ve una sola vez).
  2. Crear el Gist: ir a gist.github.com. Filename: pozos.json. Contenido: []. Click en "Create secret gist".
  3. Copiar el Gist ID de la URL (la cadena de letras y números después de tu usuario).
